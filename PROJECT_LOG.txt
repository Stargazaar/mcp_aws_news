  - No paid APIs, no accounts required for news data

  - Python suitable for a GitHub portfolio


--------------------------------------------------------------------------------
2. WHAT WAS BUILT
--------------------------------------------------------------------------------

A Python MCP server deployed on AWS EC2 that:
  1. Fetches Singapore healthcare headlines from Google News RSS (no API key)
  2. Caches results in SQLite for 1 hour to avoid hammering the feed
  3. Optionally sends an HTML email digest via Gmail SMTP
  4. Exposes all of this to Claude Desktop through the MCP protocol

Claude Desktop connects via mcp-remote (a local Node.js bridge) and can call
the server's tools in natural language during conversation.

    git pull
    source venv/bin/activate

7. CLAUDE DESKTOP CONFIGURATION (WINDOWS)
--------------------------------------------------------------------------------

  Config file path (current Claude Desktop versions):
    %LOCALAPPDATA%\Claude-Data\claude_<id>\claude_desktop_config.json
  Easiest way to open the right one: Settings -> Developer -> Edit Config.
  Older copies under %APPDATA%\Claude\ and %LOCALAPPDATA%\Packages\Claude_*\
  are no longer read. Editing them does nothing.
  The file also holds Claude Desktop's own "preferences". Edit only the
  "mcpServers" entry; never overwrite the whole file.

  mcpServers entry (replace IP after every EC2 stop/start):

    "mcpServers": {
      "sg-health-news": {
        "command": "npx",
        "args": [
          "-y",
          "mcp-remote",
          "http://<EC2_PUBLIC_IP>:8000/mcp",
          "--allow-http",
          "--header",
          "Authorization:${AUTH_HEADER}"
        ],
        "env": {
          "NODE_OPTIONS": "--use-system-ca",
          "AUTH_HEADER": "Bearer <MCP_AUTH_TOKEN from .env on EC2>"
        }
      }
    }

  Flags explained:
    --allow-http        mcp-remote blocks non-HTTPS URLs by default; this overrides
    --use-system-ca     corporate SSL inspection uses a company CA not trusted by
                        Node.js by default; this makes Node use the Windows cert store
    --header            sends the bearer token. The value comes from env because
                        Windows mangles spaces inside args, so there's no space
                        after "Authorization:"

  After editing the config:
    Fully quit Claude Desktop (system tray -> right-click -> Quit)
    Reopen it
    Check Settings -> Developer to confirm "sg-health-news" shows as connected

8. MCP TOOLS (WHAT CLAUDE CAN DO)
--------------------------------------------------------------------------------

  get_headlines(q, weeks_back, page_size)
    Fetch headlines matching a query. Results cached for 1 hour in SQLite.
    Example: "Get me MOH Singapore news from the past 2 weeks"

  send_digest_email(to_email, q, weeks_back, top_n)
    Send top N headlines as an HTML email digest via Gmail.
    Requires GMAIL_USER and GMAIL_APP_PASSWORD set in .env on EC2.
    Example: "Send a digest of the top 5 healthcare headlines to me@email.com"

  list_cached_queries()
    Show what's in the SQLite cache, when it was fetched, and how old it is.

  clear_cache()
    Wipe all cache entries so the next get_headlines call fetches fresh data.

11. KEY CONCEPTS LEARNED
--------------------------------------------------------------------------------

  MCP vs Cron:
    MCP is for INTERACTIVE use — Claude calls tools during a conversation.
    Cron/systemd timers are for SCHEDULED automation (no human in the loop).
    A weekly email digest does not need MCP; a cron job is more appropriate.
    This project uses MCP so analysts can query news interactively with Claude.

  SSE vs Streamable HTTP:
    SSE (Server-Sent Events) was the original MCP transport.
    Streamable HTTP is the current standard; Claude Desktop now expects it.
    Endpoint: /mcp (not /sse)

  mcp-remote:
    A local Node.js proxy that bridges Claude Desktop (which only supports local
    stdio servers via config) to a remote HTTP MCP server.
    Installed automatically by npx on first use.

  SQLite cache:
    Avoids hammering the Google News RSS feed on every Claude query.
    Entries expire after 1 hour; the next call fetches fresh data.
    No Redis or external service needed.

  systemd service:
    Keeps the MCP server running after SSH disconnects and restarts it on crash.
    Logs are captured by journald and readable with journalctl.

  Public IP changes:
    EC2 auto-assigned IPs are released when the instance stops.
    A new IP is assigned on start. Claude Desktop config must be updated each time.
    Elastic IP provides a fixed address, but it's billed ~$0.005/hr even while
    the instance is stopped.

  Security groups vs app auth:
    Security group = network firewall (which IPs can reach a port).
    Bearer token   = app-level check (who can use the server once reached).
    Use both: My IP rules can break when your IP changes, and the token
    still protects the server if a port is left open.

  Token usage with MCP:
    The RSS fetching/dedup/caching runs on EC2 and costs no tokens.
    Claude still spends tokens reading tool descriptions, reading the tool's
    result (the biggest part), and writing its reply. Ask for fewer results
    and start new chats to keep it small.
